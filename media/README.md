# Media

Demo videos of the Simon Says game running on the MSP430G2553 + BoosterPack MkII.
Stored with **Git LFS** (`git lfs pull` to download them after cloning).

| File | Content |
| --- | --- |
| `01-normal-gameplay.mp4` | Normal game: watch the colour sequence and repeat it with the joystick. |
| `02-colorblind-mode.mp4` | Colour-blind / symbol mode (`#`, `@`, `$`, `%`) — enabled by holding the joystick left while pressing Start. |
| `03-victory-double-speed.mp4` | Final victory screen and the double-speed restart. The 32 rounds are skipped with the S1 button shortcut (jumps to `VICTORIA_FINAL`). |
